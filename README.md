# X 推文下载 Edge 插件

一个适用于 Edge（兼容 Chrome 内核）的浏览器插件：
- 在浏览 `x.com`/`twitter.com` 推文流时，为每条推文添加 **下载DOC** 按钮；
- 支持按点赞数阈值自动下载“优质推文”；
- 下载为弱格式 Word 文件（`.doc`，内容为 HTML 结构，可直接用 Word 打开）。

## 安装方式（开发者模式）

1. 打开 Edge：`edge://extensions/`
2. 打开右上角 **开发人员模式**
3. 点击 **加载解压缩的扩展**
4. 选择本项目目录

## 使用说明

1. 打开 X 首页或任意时间线页面。
2. 插件会在每条推文操作区增加 `下载DOC` 按钮，点击即可下载。
3. 点击扩展图标可设置：
   - 是否开启自动下载；
   - 自动下载的最低点赞阈值（例如 100）。
4. 同一条推文会自动去重，避免重复下载。

## 输出格式

- 文件目录示例：`下载/x-tweets/用户名-推文ID.doc`
- 文档包含：作者、点赞数、发布时间、原始链接、推文正文、导出时间。

## 注意事项

- X 页面结构可能变动，如按钮失效可调整 `content.js` 的选择器。
- 点赞数解析支持普通数字与 `K/M` 缩写。
